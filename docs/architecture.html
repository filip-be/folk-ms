folk-ms: CMS for Bal Folk Poznań & Celtycki Wrocław

Architecture draft from the design session on 2026-11-05. Static Sites read a published JSON snapshot; one Go CMS (admin UI + API on one origin) writes it. Every cloud service sits behind a port, so Azure can be swapped for a VPS. Expected cost: under $1/month.

7. Open risks to retire early

  • Flex catch-all routing. Microsoft does not document whether a custom handler can serve arbitrary paths with routePrefix: ""; /admin and /runtime are likely host-reserved. The first plan step is a deployed spike. Fallback: Azure Container Apps with the same binary.
  • Meta Standard Access for pages_manage_posts. Very likely fine for app-role holders, but not stated explicitly. Verify in the spike with a test Page.
  • Long-run per-Organization CMS domains. Flex allows at most 3 managed certificates per app, which is fine for 2–3 Organizations. Sessions are per host.
  • JSON Schema validation vs. dependency policy. Validating fixtures needs a validator: a test-only Go module, a minimal own validator for the subset we use, or a Bun-side check.
  • Single events.json growth. Fine for years, to be revisited.
  • Cold starts. Flex scale-to-zero means about 1–2 s on the first admin request. Acceptable for an admin UI.
  • Bin purge. Purging after 30 days needs a timer trigger, or a purge on read.
